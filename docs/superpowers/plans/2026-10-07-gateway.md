Goal: augment the aPush fork and replace the independent PushHub deployment.
Architecture: aPush Express/MySQL; scoped key API and transactional queue share original channels/messages. Spec: ../specs/2026-10-07-gateway-design.md.

Global constraints: preserve upstream MIT attribution, existing database and auth password; no secrets committed; defaults wecom; bounded three attempts; no unsolicited external message sends; minimal verification per user.
